# LCA Node.js Exercises

A collection of Node.js and Express.js backend exercises built to demonstrate API route structure, middleware handling, and HTTP request testing.

## Exercises Included

* **Exercise 01: Express Routes Setup**
  * Created Express server with `products` and `employees` modular routers.
  * Implemented full CRUD endpoint handling (`GET`, `POST`, `PUT`, `PATCH`, `DELETE`).
  * Tested and verified HTTP methods via Reqable.
